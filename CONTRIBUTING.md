# Contributing to GROK

Thank you for considering contributing.

## What we care about most

1. **Real utility** — features that save people real time
2. **Clean code** — readable, typed where it helps, minimal magic
3. **Honest communication** — no hype, clear trade-offs

## How to contribute

1. Open an issue first for non-trivial changes (describe the problem and proposed solution)
2. Fork → create a focused branch → open a PR
3. Keep PRs small and well-described

## Good first contributions

- Improve agent output quality for specific task types
- Add real tools (file system, simple web fetch, etc.)
- Better examples
- Documentation improvements
- Test coverage

## Code style

- Python 3.10+
- Type hints where they add clarity
- Rich for CLI output
- Pydantic for structured data

## Commercial note

This project has an intentional commercial path.  
Contributions that strengthen the open-source core while keeping the path to a hosted Pro version clear are especially welcome.
